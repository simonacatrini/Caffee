# Caffea

Caffea is a coffee shop website I worked on while learning JavaScript. I used HTML, CSS and JavaScript.

## How to open it

Open the folder in VS Code and start Live Server from `index.html`.

## What you can try

- Search for "eclair" and press Enter. The page takes you to the desserts section.
- Add two eclairs to the cart. The total is 36 lei. Use the + and - buttons to see it change.
- Go to checkout and try the payment form with made-up card details. It's a demo.
- Write a review and use the arrows to go through the reviews. Refresh the page to see the original three again.

I used this project to practice working with the DOM and handling clicks and forms. The cart passes the order to the checkout page using sessionStorage.
